# Eighty-block stress variant audit

Unity 6000.0.72f1 / Playworks 7.2.0. Variant_Stress uses a 16 × 20 grid with 80 four-cell blocks, eight palette colors and eight bottom exits. Variant_Showcase remains available as the smaller alternative. The prepared playable scene selects Variant_Stress.

## Verified

- All 80 blocks can reach their matching exits; all 14 core test groups pass, including 5,000 randomized moves.
- Prepared scene rebuild, persistent shared meshes, Color32 vertex storage, shader import, selection/release, pooled fragment reuse, idle hints and ten active seconds before full-screen store taps pass native Unity checks.
- All 80 block renderers share one 596-vertex shape asset. Visible board + blocks: 54,386 vertices / 41,784 triangles. This is submitted geometry, not unique asset storage or a draw-call measurement.
- Repeated enqueues for all 80 blocks settle at the correct targets. 1,000 ticks moving all 80 blocks, 10,000 idle motion ticks and 10,000 hint previews each allocate 0 managed bytes on the measured Unity thread after warmup. This does not measure total application memory or browser allocations.
- Runtime source has no Instantiate, Destroy or new GameObject calls. Camera, HUD, board and eight reusable fragments are prepared in the editor.
- Removed the redundant dark floor layer: saves 5,440 vertices and 5,120 triangles on this variant. Unlit scene no longer exports default skybox/cubemap; authoring helpers are excluded from player compilation.
- Playworks exports only four selected ScriptableObjects, four meshes, two fonts, no cubemap and no source textures. Font atlases are generated by the SDK. Other variants remain authoring assets and are not exported.
- Full Playworks compilation/package succeeds; health report has no entries; ZIP CRC passes.

## Reproduce

Run `sh Tests/run_core_tests.sh`. In an isolated Unity verification copy, copy Tests/StressSceneChecks.cs into Assets/_Project/Scripts/Editor, prepare Variant_Stress with PlayableSceneBuilder.VerifyProject, then run StressSceneChecks.Run in batch mode. Keep the helper outside the production Assets tree.

## Remaining device validation

No real-device/browser FPS, frame time, actual draw calls or external store navigation was measured in this audit. The denser variant adds renderers and submitted geometry even though shared meshes keep download size low. Test the final ZIP in Playworks on a low-end target device before delivery; choose the preserved 20-block variant if it misses the target frame budget. Shared material and mesh do not guarantee a single draw call, particularly with per-renderer color overrides. No claim of an absolute minimum build size is made.
